This project demonstrates how to design **nested layouts** using only **HTML** and **CSS**, focusing on creating structured, multi-level UI components such as video cards, profile sections, follow cards, and video suggestion layouts — all inspired by popular platforms like YouTube and Twitter.

## 🧾 Project Overview

The **Nested Layouts** project explores how HTML elements can be structured within one another to form layered and reusable layouts. Each section of the webpage is built using `<div>` containers and styled using **pure CSS**, emphasizing **positioning, spacing, and visual hierarchy**.

The project includes:
- YouTube-style **video cards**  
- Twitter-like **profile and follow sections**  
- Compact **video suggestion layouts**  
- Use of **inline-block** and **nested divs** for flexible layout control  

---

## 🧱 Features Implemented

### 🎬 YouTube-Style Video Cards
- Showcases a video thumbnail, profile picture, title, channel name, and view stats  
- Built using nested `<div>` elements for structure  
- Utilizes CSS `display: inline-block` for side-by-side alignment  

### 👤 Profile Card
- Displays a user’s profile image with basic information such as name, occupation, and role  
- Demonstrates **alignment and spacing** between images and text  

### 🤝 Follow Card
- Includes a profile picture, short bio, and a **Follow** button  
- Highlights use of **nested containers** and **button styling**

### 👥 Multiple Follow Cards
- Demonstrates how repetitive elements can be structured for a clean, consistent UI  
- Each card uses the same base structure for uniformity  

### 📺 Video Suggestions Layout
- Mimics YouTube’s sidebar video recommendations  
- Combines **image and text containers** to form compact, scrollable suggestion items

## 📚 Theory Overview

### 🔹 Nested Layouts
- A **nested layout** means placing one layout or component inside another.  
- This allows complex designs like dashboards, cards, or lists to be broken into smaller, manageable sections.  

### 🔹 Use of `<div>` Elements
- `<div>` stands for *division* and is one of the most common container elements in HTML.  
- It allows grouping related elements together to apply common styles or positioning.

### 🔹 CSS Display Property
- `display: inline-block` allows multiple block-level elements to sit beside each other while maintaining their width and height.
- `vertical-align: top` helps align cards neatly when they vary in height.  

### 🔹 CSS Styling Concepts Used
- **Box Model** (margin, border, padding)
- **Border Radius** for rounded elements  
- **Font Styling and Hierarchy** for readability  
- **Object Fit** and **Alignment** for image control  
- **Color and Shadows** for a visually appealing interface
