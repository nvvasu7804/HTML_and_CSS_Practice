# 🎨 CSS Buttons Showcase  

A simple yet elegant **HTML + CSS project** that demonstrates how to design modern, responsive, and interactive buttons inspired by real-world websites like **YouTube, Uber, Amazon, GitHub, Bootstrap, and LinkedIn**.  

This project focuses on building beautiful UI components using **pure CSS transitions, hover effects, and box shadows** — no frameworks or JavaScript required.

## 🧱 Code Explanation

Here’s a small breakdown of how a button effect works:

```css
.subscribe-button {
  background-color: rgb(179, 9, 9);
  color: white;
  border: none;
  padding: 10px;
  cursor: pointer;
  transition: opacity 0.15s;
}

.subscribe-button:hover {
  opacity: 0.8;
}

.subscribe-button:active {
  opacity: 0.5;
}
```

**Explanation:**

* `transition: opacity 0.15s;` ensures smooth fading animation.
* `:hover` reduces opacity slightly when the user hovers.
* `:active` creates a click feedback effect.
