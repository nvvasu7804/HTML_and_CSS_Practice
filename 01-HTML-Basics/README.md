## 🏗️ HTML Structure

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>HTML-Basics</title>
  </head>
  <body>
    ...
  </body>
</html>
```

- `<!DOCTYPE html>` → Defines the document as HTML5.
- `<html>` → Root of the document.
- `<head>` → Contains metadata, title, and viewport settings.
- `<body>` → Displays the visible page content.

## 🔘 Buttons Example

```html
<div>
  <button>Click</button>
</div>
<div>
  <button>You</button>
  <br />
  <button>Me</button>
</div>
```

- `<button>` creates clickable elements.
- `<br />` adds a line break for spacing.

---

## 📝 Paragraphs Example

```html
<div>
  <p>Hello, World!</p>
</div>
<div>
  <p>Today I went to grocery store to buy some eggs and vegetables.</p>
</div>
```

- `<p>` defines text paragraphs.
- Text is displayed as separate blocks for clarity.

---

## 🔗 Hyperlink Example

```html
<div>
  <a href="https://www.google.com/" target="_blank">Search With Google</a>
</div>
```

- `<a>` defines a link.
- `href` specifies the destination URL.
- `target="_blank"` opens the link in a new tab.
