## 🧾 Project Overview

The project showcases how to effectively use **div containers**, **CSS layouts**, and **basic design concepts** to structure a clean and visually appealing web page.  
It includes multiple UI sections built purely with HTML and CSS — no JavaScript.

This project helps beginners understand:
- How to divide content into logical sections using `<div>`
- How to use **CSS classes** for styling and layout
- The use of **box shadows**, **borders**, and **alignment**
- How to create simple web UI components resembling popular platforms

## 📚 Theory Overview

### 🔹 The `<div>` Tag
- The `<div>` element is a block-level container used to group HTML elements together.
- It doesn’t add semantic meaning by itself but helps in **organizing structure** and **applying styles** via CSS.

### 🔹 CSS Display Properties
- `display: inline-block` allows elements to sit side by side while maintaining block-like behavior.  
- `box-shadow` creates a realistic shadow effect to enhance visual hierarchy.  
- `object-fit: cover` ensures images maintain proper aspect ratios inside their containers.

### 🔹 Web Design Concept Used
- **Consistency** in font and padding  
- **Visual grouping** using containers  
- **Responsive-friendly units**  
- **Clear hierarchy** of content and spacing
